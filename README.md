Fitness Coach Eithan Smith - Personal Trainer Portfolio

Este proyecto es una web diseñada para un coach personal, enfocada en la conversión de clientes y la exposición de servicios de entrenamiento y nutrición. El sitio incluye secciones de planes personalizados, testimonios y contacto directo.

Características: Diseño responsive, optimización de imágenes y arquitectura limpia.

Tecnologías: HTML5, CSS3 (Flexbox/Grid), JavaScript.
